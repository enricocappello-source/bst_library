# C++ Binary Search Tree (BST)
Project Overview
This project contain a bynary search tree (BST) and the main function to menage the structure.
the code is write entirely with c++.



Feature,Status,Notes
Recursive insert,Complete,Successfully adds new nodes while maintaining the BST invariant.
Recursive search,Complete,Efficiently finds a target value in the tree.
deleteNode,Complete,"Handles all three cases (leaf, one child, two children) correctly."
height Calculation,Complete,Calculates the maximum depth of the tree recursively.
Inorder Traversal,Complete,Prints nodes in sorted order (Left → Root → Right).
Preorder Traversal,Complete,Prints nodes (Root → Left → Right).
Postorder Traversal,Complete,"Prints nodes (Left → Right → Root), crucial for memory cleanup."
