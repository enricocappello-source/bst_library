# C++ Binary Search Tree (BST)
Project Overview
This project contain a bynary search tree (BST) and the main function to menage the structure.
the code is write entirely with c++.



Feature
 -Recursive insert.        Successfully adds new nodes while maintaining the BST invariant.

 -Recursive search.        Efficiently finds a target value in the tree.

 -deleteNode.              "Handles all three cases (leaf, one child, two children) correctly."

 -height Calculation.      Calculates the maximum depth of the tree recursively.

 -Inorder Traversal.       Prints nodes in sorted order (Left → Root → Right).

 -Preorder Traversal.      Prints nodes (Root → Left → Right).

 -Postorder Traversal.       "Prints nodes (Left → Right → Root), crucial for memory cleanup."
